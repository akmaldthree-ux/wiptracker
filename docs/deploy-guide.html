Memahami Struktur Proyek

Pahami apa yang ada di dalam project sebelum upload

⚠️
Kenapa ukuran download dari GitHub hanya ~1 MB? Folder vendor/ (berisi Laravel & semua library PHP, ~40 MB) tidak ikut di Git karena ada di .gitignore. Ini normal. Kamu harus menjalankan composer install di server untuk mengunduhnya.
STRUKTUR FOLDER PROJECT
tritory.id/                ← Nama folder di server (sesuai domain)
├── app/                   ← Logic aplikasi (Controllers, Models)
├── bootstrap/             ← Bootstrap Laravel
├── config/                ← Konfigurasi aplikasi
├── database/              ← Migrations dan seeders
├── public/                ← ⭐ Document Root mengarah ke sini
│   ├── index.php          ← Entry point
│   ├── css/               ← Bootstrap, Bootstrap Icons (sudah ada)
│   └── js/                ← Bootstrap JS, Chart.js (sudah ada)
├── resources/             ← Views (Blade templates)
├── routes/                ← Definisi routes
├── storage/               ← File upload, cache, logs
├── vendor/                ← ❌ TIDAK ada (harus composer install)
├── .env                   ← ❌ TIDAK ada (harus dibuat dari .env.example)
├── .env.example           ← Template konfigurasi
└── composer.json          ← Definisi dependencies
✅
Aset frontend sudah tersedia: File CSS/JS (Bootstrap, Chart.js) sudah ter-commit di Git dan tidak perlu npm install. Hanya butuh composer install saja.

Upload File ke Server

Pilih salah satu metode upload berikut

Metode Upload

📂 Metode A — File Manager (Pemula)
  • Download project dari GitHub sebagai ZIP
  • Buka File Manager di cPanel
  • Navigasi ke root directory (~/)
  • Upload ZIP, lalu extract
  • Rename folder ke tritory.id
⚡ Metode B — Git Clone (Direkomendasikan)
  • Buka Terminal di cPanel
  • Jalankan perintah git clone di bawah
  • Otomatis sudah dengan nama folder yang benar
  • Mudah update di kemudian hari
TERMINAL — Git Clone (Rekomendasi)
# Masuk ke home directory
cd ~

# Clone repository
git clone https://github.com/akmaldthree-ux/wiptracker.git tritory.id

# Verifikasi folder sudah ada
ls -la | grep tritory.id
TERMINAL — Jika pakai ZIP (Metode A)
# Setelah extract ZIP, rename folder
# (sesuaikan nama folder hasil extract)
mv wiptracker-main ~/tritory.id

# Verifikasi
ls ~/tritory.id
📌
Lokasi folder yang benar: Folder project harus berada di /home/[username]/tritory.id/ — bukan di dalam public_html.

Pengaturan Domain di cPanel

Arahkan Document Root domain ke folder public Laravel

🔑
Langkah terpenting! Document Root harus mengarah ke tritory.id/public — bukan ke tritory.id langsung. Jika salah, aplikasi tidak akan bisa diakses.
  • 🌐

    Buka Domains di cPanel

    Masuk ke cPanel → cari menu Domains atau Addon Domains. Jika tritory.id adalah domain utama, masuk ke Domains → Manage Domains.

  • 📁

    Ubah Document Root

    Temukan tritory.id di daftar domain, klik Manage atau edit, lalu ubah Document Root menjadi:

    tritory.id/public

    Atau path lengkapnya: /home/[username]/tritory.id/public

  • ✅

    Simpan dan Verifikasi

    Klik Save. Untuk verifikasi, akses https://tritory.id — jika muncul halaman Laravel (meski error 500 karena belum setup), berarti Document Root sudah benar.

💡
Kenapa harus ke /public? Laravel menyimpan file publik (index.php, aset CSS/JS) di folder public/. Folder lainnya (app, config, database) tidak boleh bisa diakses langsung dari browser.

File .env & Database MySQL

Buat konfigurasi environment dan setup database

A. Buat Database MySQL di cPanel

  • 🗄️

    Buat Database Baru

    cPanel → MySQL Databases → Create New Database. Contoh nama: dpis_prod

  • 👤

    Buat User Database

    Scroll ke bawah → Add New User. Buat username dan password yang kuat. Contoh: dpis_user

  • 🔗

    Hubungkan User ke Database

    Di bagian "Add User To Database" → pilih user dan database yang baru dibuat → klik Add → centang All Privileges

B. Buat file .env

TERMINAL — Buat dari template
cd ~/tritory.id
cp .env.example .env
FILE — .env (edit sesuai data kamu)
APP_NAME="DPIS"
APP_ENV=production
APP_KEY=                          # akan di-generate otomatis
APP_DEBUG=false
APP_URL=https://tritory.id

LOG_CHANNEL=stack
LOG_LEVEL=error

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=nama_database_kamu    # ← ganti
DB_USERNAME=nama_user_kamu        # ← ganti
DB_PASSWORD=password_kamu         # ← ganti

CACHE_STORE=file
SESSION_DRIVER=file
QUEUE_CONNECTION=sync

MAIL_MAILER=smtp
MAIL_HOST=mail.tritory.id
MAIL_PORT=587
MAIL_USERNAME=noreply@tritory.id
MAIL_PASSWORD=
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@tritory.id
MAIL_FROM_NAME="DPIS"
⚠️
Catatan nama database cPanel: cPanel otomatis menambahkan prefix username di depan nama database dan user. Contoh: jika username cPanel = dthree, nama database = dpis_prod, maka yang diisi di .env adalah dthree_dpis_prod.

Install Dependencies (Composer)

Install semua library PHP yang dibutuhkan Laravel

TERMINAL — Install Composer dependencies
cd ~/tritory.id

# Install dependencies (tanpa dev packages untuk production)
composer install --optimize-autoloader --no-dev

# Verifikasi berhasil — folder vendor harus ada
ls vendor/ | head -5
⏱️
Proses ini memakan waktu 2–5 menit tergantung kecepatan server. Sabar dan jangan tutup terminal. Jika selesai, folder vendor/ akan berisi ratusan file (~40 MB).

Jika Composer tidak tersedia:

TERMINAL — Install Composer manual
cd ~
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php -r "unlink('composer-setup.php');"

# Gunakan dengan cara:
php ~/composer.phar install --optimize-autoloader --no-dev -d ~/tritory.id

Perintah Artisan

Setup aplikasi menggunakan Laravel Artisan CLI

TERMINAL — Jalankan semua perintah ini secara berurutan
cd ~/tritory.id

# 1. Generate Application Key (wajib, hanya sekali)
php artisan key:generate

# 2. Jalankan migrasi database (buat semua tabel)
php artisan migrate --force

# 3. Jalankan seeder (data awal: admin, stasiun, dll)
php artisan db:seed --force

# 4. Buat symlink storage (untuk file upload)
php artisan storage:link
⚠️
Jalankan migrate hanya sekali! Jika dijalankan lagi saat tabel sudah ada, gunakan php artisan migrate:fresh --seed --force (ini akan menghapus semua data). Untuk update, gunakan php artisan migrate --force.

Verifikasi migrasi berhasil:

php artisan migrate:status

Permission & Cache

Atur permission file dan aktifkan cache untuk performa optimal

TERMINAL — Set permission folder
cd ~/tritory.id

# Permission untuk storage dan cache (wajib writable)
chmod -R 775 storage bootstrap/cache
chown -R $USER:$USER storage bootstrap/cache
TERMINAL — Aktifkan cache Laravel
cd ~/tritory.id

# Cache konfigurasi
php artisan config:cache

# Cache routes
php artisan route:cache

# Cache views (Blade templates)
php artisan view:cache
💡
Kapan perlu clear cache? Setiap kali kamu mengubah file .env atau file konfigurasi, jalankan php artisan config:clear && php artisan config:cache.

Perintah clear cache (jika ada masalah):

php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan cache:clear

SSL Certificate (HTTPS)

Aktifkan HTTPS gratis dengan Let's Encrypt

  • 🔒

    Aktifkan Let's Encrypt di cPanel

    Masuk ke cPanel → Security → SSL/TLS Status atau Let's Encrypt SSL → pilih domain tritory.id → klik Issue.

  • ↩️

    Aktifkan Force HTTPS

    Di cPanel → Domains → Redirects, buat redirect dari http://tritory.id ke https://tritory.id.

    Atau tambahkan di file .htaccess dalam folder public/:

    # Tambahkan SEBELUM baris "RewriteEngine On"
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
  • ✔️

    Verifikasi APP_URL di .env

    Pastikan APP_URL=https://tritory.id (dengan https, tanpa slash di akhir), lalu jalankan php artisan config:cache.

Troubleshooting

Masalah umum dan cara mengatasinya

Error 500 biasanya disebabkan oleh:

  1. File .env belum dibuat atau konfigurasi salah
  2. Folder vendor/ belum ada (belum composer install)
  3. APP_KEY belum di-generate
  4. Permission storage tidak writable
# Cek error log
tail -50 ~/tritory.id/storage/logs/laravel.log

# Fix cepat
cd ~/tritory.id
php artisan key:generate
chmod -R 775 storage bootstrap/cache
php artisan config:clear

Koneksi database gagal. Periksa hal berikut:

  • Nama database di .env menggunakan format username_namadb
  • Username database format username_namauser
  • Password sudah benar
  • User database sudah di-assign ke database dengan All Privileges
# Test koneksi database
php artisan tinker
# Ketik: DB::connection()->getPdo()
# Jika berhasil keluar output PDO object

Coba langkah berikut:

cd ~/tritory.id

# Sementara aktifkan debug
# Edit .env: APP_DEBUG=true
# Refresh browser, lihat error message

# Setelah fix, matikan kembali
# Edit .env: APP_DEBUG=false
php artisan config:cache

Kemungkinan penyebab:

  • Document Root salah (tidak ke /public)
  • APP_URL di .env salah
  • File CSS/JS di public/css dan public/js tidak ter-upload
# Cek file aset ada
ls ~/tritory.id/public/css/
ls ~/tritory.id/public/js/

# Update APP_URL jika perlu
# Edit .env: APP_URL=https://tritory.id
php artisan config:cache
# Jalankan dengan memory limit lebih besar
COMPOSER_MEMORY_LIMIT=-1 composer install --no-dev --optimize-autoloader
# Hapus symlink lama jika ada
rm -f ~/tritory.id/public/storage

# Buat ulang
php artisan storage:link

Jika ada reverse proxy/load balancer di depan server, tambahkan ini di app/Http/Middleware/TrustProxies.php:

// Di file TrustProxies.php
protected $proxies = '*';

Setelah Deploy — Langkah Selanjutnya

Hal yang perlu dilakukan setelah aplikasi berhasil jalan

🎉
Selamat! Aplikasi sudah live di https://tritory.id Lakukan langkah-langkah berikut untuk memastikan sistem siap digunakan.
  • 🔐

    Ganti Semua Password Default

    Login sebagai admin → menu Users → edit setiap user dan ubah password. Jangan biarkan password password digunakan di production.

  • 🏭

    Setup Master Data

    Masuk ke menu Master Data → lengkapi data Produk, Series, Warna, Ukuran, Stasiun, dan Tempat Sewing sesuai data nyata perusahaan.

  • 👥

    Buat Akun User

    Tambahkan akun untuk setiap operator/supervisor di setiap stasiun. Assign role yang sesuai.

  • 📋

    Input Order Produksi Pertama

    Coba buat Production Order pertama untuk menguji alur: Order → Cutting Plan → WIP Input → Handover → Dashboard.

  • 🔄

    Setup Auto-Update (Opsional)

    Untuk mempermudah update di masa depan, cukup jalankan:

    cd ~/tritory.id
git pull origin main
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan config:cache && php artisan route:cache && php artisan view:cache
