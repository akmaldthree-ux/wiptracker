2
Persiapan di Komputer Lokal
💻
Langkah ini dilakukan di komputer Anda, bukan di server hosting.
Download Project dari GitHub
# Clone repository
git clone https://github.com/akmaldthree-ux/wiptracker.git tritory.id
cd tritory.id
git checkout claude/clever-bohr-6i3l8a

Folder diberi nama tritory.id agar sama dengan nama folder di server.

Install Composer Dependencies
composer install --optimize-autoloader --no-dev
Buat File .env

Buat file .env di dalam folder tritory.id/:

APP_NAME="DPIS - DTHREE Production"
APP_ENV=production
APP_KEY= ← kosongkan, diisi otomatis nanti
APP_DEBUG=false
APP_URL=https://tritory.id

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=namauser_dpis ← GANTI (lihat Langkah 3)
DB_USERNAME=namauser_dpis ← GANTI (lihat Langkah 3)
DB_PASSWORD=PasswordKuat123! ← GANTI

SESSION_DRIVER=file
SESSION_LIFETIME=30
CACHE_STORE=file
QUEUE_CONNECTION=sync

LOG_CHANNEL=single
LOG_LEVEL=error

MAIL_FROM_ADDRESS="noreply@tritory.id"
MAIL_FROM_NAME="DPIS System"
⚠️
Nilai berwarna kuning wajib diganti sesuai data database hosting Anda.
Buat ZIP Archive

Windows: Klik kanan folder tritory.id → Send to → Compressed (zipped) folder

Mac / Linux:

cd ..   # keluar dari folder tritory.id
zip -r tritory.id.zip tritory.id \
  --exclude "tritory.id/.git/*" \
  --exclude "tritory.id/node_modules/*" \
  --exclude "tritory.id/database/*.sqlite"

Ukuran ZIP normalnya 20–40 MB (sudah termasuk folder vendor/).

3
Setup Database MySQL di cPanel
Buka MySQL Databases

Login cPanel → cari menu "MySQL® Databases"

Buat Database Baru

Kolom "Create New Database" → ketik dpis → klik Create Database

ℹ️
Nama lengkap otomatis: namauser_dpis — ini yang diisi ke DB_DATABASE di file .env
Buat MySQL User Baru

Scroll ke "MySQL Users" → "Add New User"

  • Username: dpis
  • Password: gunakan tombol Password Generator
  • Klik Create User
Hubungkan User ke Database

Scroll ke "Add User To Database" → pilih user & database → klik Add

Centang ALL PRIVILEGES → klik Make Changes

Catat Informasi Database
DB_DATABASE = namauser_dpis
DB_USERNAME = namauser_dpis
DB_PASSWORD = [password yang dibuat]
DB_HOST = localhost

Update nilai ini di file .env sebelum upload.

4
Upload Project ke Server
Upload ZIP via File Manager cPanel
  1. cPanel → File Manager
  2. Navigasi ke /home/namauser/
  3. Klik Upload → pilih tritory.id.zip
  4. Tunggu hingga upload 100%
Ekstrak ZIP
  1. Klik kanan tritory.id.zip → Extract
  2. Tujuan extract: /home/namauser/
  3. Klik Extract File(s)
Hasil Akhir Struktur Folder
/home/namauser/
├── public_html/ ← domain utama hosting (biarkan)
│
└── tritory.id/ ← folder project Laravel ✅
    ├── app/
    ├── bootstrap/
    ├── config/
    ├── database/
    ├── public/ ← Document Root diarahkan ke sini ✅
    │   ├── index.php
    │   ├── .htaccess
    │   ├── css/
    │   └── js/
    ├── resources/
    ├── routes/
    ├── storage/
    ├── vendor/
    └── .env
✅
Tidak perlu memindahkan file apapun. Tidak perlu mengedit index.php. Cukup arahkan Document Root ke folder tritory.id/public.
5
Set Document Root → tritory.id/public
🎯
Ini langkah terpenting. Document Root adalah folder yang dibuka server saat seseorang mengakses tritory.id di browser.

Jika tritory.id adalah Addon Domain

Buka Addon Domains

cPanel → Addon Domains

Edit Document Root

Cari tritory.id → klik Manage atau ikon edit

Ubah Document Root menjadi:

tritory.id/public

Atau path lengkapnya: /home/namauser/tritory.id/public

Simpan

Klik Save atau Change

Jika tritory.id adalah Domain Utama Hosting

cPanel → File Manager

Buka file /home/namauser/public_html/.htaccess → tambahkan baris berikut:

RewriteEngine On
RewriteRule ^(.*)$ /tritory.id/public/$1 [L]

Atau hubungi support hosting untuk mengubah document root via server config.

✅
Cara kerja setelah Document Root diset:
Browser buka tritory.id → Server buka /home/namauser/tritory.id/public/ → File index.php ditemukan → Laravel berjalan ✅
6
Setup PHP di cPanel

Set Versi PHP

  1. cPanel → MultiPHP Manager
  2. Centang domain tritory.id
  3. Pilih versi: PHP 8.3 atau PHP 8.4
  4. Klik Apply

Aktifkan Ekstensi PHP

  1. cPanel → MultiPHP INI Editor → pilih tritory.id
  2. Pastikan ekstensi berikut aktif:
✓ pdo_mysql ✓ mbstring ✓ openssl ✓ tokenizer ✓ xml ✓ json ✓ bcmath ✓ fileinfo ✓ intl ✓ zip ✓ curl

Klik Save

Aktifkan SSL (HTTPS)

  1. cPanel → SSL/TLS → Let's Encrypt
  2. Pilih domain tritory.id → klik Issue
  3. Tunggu beberapa menit → SSL aktif gratis ✅
7
Jalankan Perintah Artisan via Terminal

Buka cPanel → Terminal, lalu masuk ke folder project:

cd ~/tritory.id
⚠️
Jalankan perintah berikut secara berurutan. Jangan lewati satu pun.
Generate Application Key
php artisan key:generate

✅ Output: Application key set successfully.

Set Permission Folder
chmod -R 775 storage
chmod -R 775 bootstrap/cache
Jalankan Migrasi Database
php artisan migrate --force

✅ Membuat semua tabel database (4 migration)

Isi Data Awal
php artisan db:seed --force

✅ Membuat roles, stasiun, dan akun user default

Buat Symlink Storage
php artisan storage:link
Optimasi Cache Production
php artisan config:cache
php artisan route:cache
php artisan view:cache

✅ Sistem siap dengan performa optimal

Troubleshooting
500 Internal Server Error ▼

Penyebab: Error PHP di aplikasi

# Lihat log error
tail -50 ~/tritory.id/storage/logs/laravel.log

# Aktifkan debug sementara di .env:
APP_DEBUG=true
# Refresh → lihat error → matikan lagi:
APP_DEBUG=false
php artisan config:cache
404 Semua URL Tidak Ditemukan ▼

Penyebab: Document Root belum diarahkan ke folder public, atau mod_rewrite belum aktif.

  • Pastikan Document Root sudah mengarah ke /home/namauser/tritory.id/public
  • Pastikan file .htaccess ada di dalam folder tritory.id/public/
  • Hubungi support hosting, minta aktifkan mod_rewrite
419 Page Expired / CSRF Error ▼ 
chmod -R 775 ~/tritory.id/storage/framework/sessions
php artisan config:clear && php artisan cache:clear
CSS Tampilan Rusak / Tidak Ada Style ▼

Penyebab: APP_URL salah atau file CSS tidak ada.

  • Pastikan APP_URL=https://tritory.id di file .env (bukan localhost)
  • Pastikan folder tritory.id/public/css/ berisi bootstrap.min.css
  • Jalankan php artisan config:cache setelah edit .env
DB SQLSTATE: Access Denied ▼

Penyebab: Kredensial database salah di .env

# Cek isi .env
cat ~/tritory.id/.env | grep DB_

# Setelah edit .env:
php artisan config:clear
php artisan config:cache
🔒 HTTPS Tidak Berjalan / Mixed Content ▼
  • Pastikan APP_URL=https://tritory.id (pakai https, bukan http)
  • Aktifkan Let's Encrypt di cPanel → SSL/TLS
  • Aktifkan Force HTTPS di cPanel jika tersedia
