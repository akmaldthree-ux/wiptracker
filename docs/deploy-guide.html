2
Persiapan di Komputer Lokal
💻
Langkah ini dilakukan di komputer Anda sendiri, bukan di server hosting.
Download / Clone Project dari GitHub
# Clone repository
git clone https://github.com/akmaldthree-ux/wiptracker.git dpis
cd dpis
git checkout claude/clever-bohr-6i3l8a

Atau download ZIP dari GitHub → Extract ke folder bernama dpis

Install Composer Dependencies
composer install --optimize-autoloader --no-dev

Pastikan Composer sudah terinstall. Proses ini membutuhkan koneksi internet dan memakan waktu beberapa menit.

Buat File .env untuk Production

Buat file bernama .env (bukan .env.example) dengan isi berikut:

APP_NAME="DPIS - DTHREE Production"
APP_ENV=production
APP_KEY= ← kosongkan, diisi otomatis nanti
APP_DEBUG=false
APP_URL=https://yourdomain.com ← GANTI

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=namauser_dpis ← GANTI (lihat Langkah 3)
DB_USERNAME=namauser_dpis ← GANTI (lihat Langkah 3)
DB_PASSWORD=PasswordKuat123! ← GANTI

SESSION_DRIVER=file
SESSION_LIFETIME=30
CACHE_STORE=file
QUEUE_CONNECTION=sync

LOG_CHANNEL=single
LOG_LEVEL=error
⚠️
Teks berwarna kuning wajib diganti sesuai data Anda. Jangan lupa ganti yourdomain.com dengan domain asli Anda.
Buat ZIP Archive Project

Windows: Klik kanan folder dpis → Send to → Compressed (zipped) folder

Mac / Linux:

cd ..   # keluar dari folder dpis
zip -r dpis.zip dpis \
  --exclude "dpis/.git/*" \
  --exclude "dpis/node_modules/*" \
  --exclude "dpis/database/*.sqlite"

Ukuran ZIP normalnya 20–40 MB (termasuk folder vendor/)

3
Setup Database MySQL di cPanel
Buka MySQL Databases

Login ke cPanel → cari menu "MySQL® Databases"

Buat Database Baru

Di kolom "Create New Database", ketik: dpis → klik Create Database

ℹ️
Nama lengkap otomatis menjadi namauser_dpis — ini yang diisi ke DB_DATABASE
Buat MySQL User Baru

Scroll ke "MySQL Users" → "Add New User"

  • Username: dpis
  • Password: gunakan tombol Password Generator untuk membuat password yang kuat
  • Klik Create User
Hubungkan User ke Database

Scroll ke "Add User To Database"

  • Pilih User: namauser_dpis
  • Pilih Database: namauser_dpis
  • Klik Add
  • Di halaman berikutnya: centang ALL PRIVILEGES → klik Make Changes
Catat Informasi Database
DB_DATABASE = namauser_dpis
DB_USERNAME = namauser_dpis
DB_PASSWORD = [password yang Anda buat]
DB_HOST = localhost

Simpan catatan ini, akan dibutuhkan saat edit file .env

4
Upload & Konfigurasi File di cPanel
Upload ZIP via File Manager
  1. cPanel → File Manager
  2. Navigasi ke /home/namauser/ (satu level di atas public_html)
  3. Klik Upload → pilih dpis.zip
  4. Tunggu hingga upload 100% selesai
  5. Klik kanan dpis.zip → Extract → tujuan: /home/namauser/
Struktur Folder Setelah Diekstrak
/home/namauser/
├── public_html/ ← yang diakses browser
│
└── dpis/ ← folder Laravel hasil extract
    ├── app/
    ├── bootstrap/
    ├── config/
    ├── database/
    ├── public/ ← isi folder ini dipindah ke public_html
    ├── resources/
    ├── routes/
    ├── storage/
    ├── vendor/
    └── .env
Pindahkan Isi dpis/public/ ke public_html/
  1. Masuk ke folder /home/namauser/dpis/public/
  2. Tekan Ctrl+A (Select All)
  3. Klik Move di toolbar
  4. Tujuan: /home/namauser/public_html/
  5. Klik Move File(s)

Setelah dipindah, public_html/ berisi:

public_html/
├── index.php ← entry point (akan diedit)
├── .htaccess ← URL rewriting
├── favicon.ico
├── robots.txt
├── css/
│   ├── bootstrap.min.css
│   └── bootstrap-icons/
└── js/
    ├── bootstrap.bundle.min.js
    └── chart.umd.min.js
Edit index.php di public_html/

Klik kanan index.php → Edit. Ubah 2 baris berikut:

Baris 1 — Path autoload:

// SEBELUM:
require __DIR__.'/../vendor/autoload.php';

// SESUDAH:
require __DIR__.'/../dpis/vendor/autoload.php';

Baris 2 — Path bootstrap:

// SEBELUM:
$app = require_once __DIR__.'/../bootstrap/app.php';

// SESUDAH:
$app = require_once __DIR__.'/../dpis/bootstrap/app.php';

Klik Save Changes

6
Setup PHP di cPanel

A. Set Versi PHP

  1. cPanel → MultiPHP Manager
  2. Centang domain Anda
  3. Pilih versi: PHP 8.3 atau PHP 8.4
  4. Klik Apply

B. Aktifkan Ekstensi PHP

  1. cPanel → MultiPHP INI Editor → pilih domain
  2. Pastikan ekstensi berikut dicentang:
✓ pdo_mysql ✓ mbstring ✓ openssl ✓ tokenizer ✓ xml ✓ ctype ✓ json ✓ bcmath ✓ fileinfo ✓ intl ✓ zip ✓ curl

Klik Save

7
Jalankan Perintah Artisan via Terminal

Buka cPanel → Terminal (atau SSH dengan PuTTY/Terminal):

ssh namauser@yourdomain.com

Masuk ke folder Laravel:

cd ~/dpis
⚠️
Jalankan perintah berikut SECARA BERURUTAN. Jangan lewati satu pun.
Generate Application Key
php artisan key:generate

✓ Output yang benar: Application key set successfully.

Set Permission Folder
chmod -R 775 storage
chmod -R 775 bootstrap/cache
Jalankan Migrasi Database
php artisan migrate --force

✓ Akan membuat semua tabel database (4 migration files)

Isi Data Awal (Seeder)
php artisan db:seed --force

✓ Membuat roles, stasiun produksi, dan akun user default

Buat Symlink Storage
php artisan storage:link
Optimasi Cache Production
php artisan config:cache
php artisan route:cache
php artisan view:cache

✓ Sistem siap digunakan dengan performa optimal

Troubleshooting
500 Internal Server Error ▼

Penyebab: Error PHP di aplikasi

# Lihat log error terbaru
tail -50 ~/dpis/storage/logs/laravel.log

# Aktifkan debug sementara — edit .env:
APP_DEBUG=true
# Refresh browser, lihat error, lalu matikan lagi:
APP_DEBUG=false
php artisan config:cache
419 Page Expired / CSRF Error ▼

Penyebab: Folder session tidak bisa ditulis

chmod -R 775 ~/dpis/storage/framework/sessions
php artisan config:clear
php artisan cache:clear
404 Semua URL Tidak Ditemukan ▼

Penyebab: .htaccess tidak aktif atau mod_rewrite belum diaktifkan

  • Pastikan file .htaccess ada di public_html/
  • Hubungi support hosting, minta aktifkan mod_rewrite
  • Atau tambahkan di awal .htaccess: Options +FollowSymLinks
CSS Halaman Tampil Tanpa Styling ▼

Penyebab: File CSS tidak terpindah ke public_html/ atau APP_URL salah

  • Pastikan public_html/css/bootstrap.min.css ada
  • Pastikan public_html/css/bootstrap-icons/ ada (folder ikon)
  • Pastikan APP_URL di .env sesuai domain asli (bukan localhost)
DB SQLSTATE: Access Denied ▼

Penyebab: Kredensial database salah atau user belum diberi akses

# Cek isi .env
cat ~/dpis/.env | grep DB_

# Setelah edit .env, refresh config:
php artisan config:clear
php artisan config:cache

Pastikan user MySQL sudah di-assign ke database dengan ALL PRIVILEGES di cPanel MySQL Databases.

⚙️ Tidak Ada Akses Terminal / SSH ▼

Buat file sementara public_html/setup.php:

<?php
// HAPUS FILE INI SEGERA SETELAH SELESAI!
chdir(__DIR__ . '/../dpis');
require __DIR__ . '/../dpis/vendor/autoload.php';
$app = require_once __DIR__ . '/../dpis/bootstrap/app.php';
$kernel = $app->make(Illuminate\Contracts\Console\Kernel::class);
echo "<pre>";
$kernel->call('key:generate');
$kernel->call('migrate', ['--force' => true]);
$kernel->call('db:seed', ['--force' => true]);
$kernel->call('config:cache');
$kernel->call('route:cache');
$kernel->call('view:cache');
echo "</pre>Done!";

Akses: https://yourdomain.com/setup.php

🗑️
Hapus file setup.php SEGERA setelah selesai! File ini sangat berbahaya jika dibiarkan.
