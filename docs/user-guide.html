Pendahuluan & Gambaran Sistem

Tentang DPIS dan alur produksi yang didukung

🏭 Apa itu DPIS?

DTHREE Production Integration System (DPIS) adalah sistem informasi manajemen produksi berbasis web yang dirancang khusus untuk PT DTHREE SUKSES MULIA. Sistem ini mengintegrasikan seluruh alur produksi garmen — dari perencanaan, eksekusi di lantai produksi, hingga pelaporan manajemen.

Sistem dapat diakses melalui browser di alamat: https://tritory.id

⚙️ Fitur Utama

📋

Production Order

Buat dan kelola order produksi lengkap dengan SKU, target quantity, dan deadline.

✂️

Cutting Plan

Jadwalkan dan monitor proses cutting dengan kalender visual dan tracking bundle.

📊

WIP Tracker

Input dan pantau Work In Progress di setiap stasiun secara real-time.

🔄

Handover

Catat serah terima barang antar stasiun dengan verifikasi dan konfirmasi digital.

📦

Bahan Baku

Kelola stok bahan baku, terima pengiriman, dan pantau minimum stock.

💰

Budget & Biaya

Rencanakan dan pantau anggaran produksi dibandingkan realisasi aktual.

📈

Dashboard & Laporan

Visualisasi data produksi dengan grafik interaktif dan laporan yang bisa dicetak.

🔔

Notifikasi

Alert otomatis untuk deadline mendekati, stok menipis, dan handover menunggu.

🔀 Alur Produksi

DPIS mengikuti alur produksi garmen PT DTHREE SUKSES MULIA secara berurutan:

Setiap perpindahan barang antar stasiun dicatat melalui fitur Handover dan dipantau melalui WIP Tracker.

Login & Navigasi

Cara masuk ke sistem dan memahami antarmuka

🔐 Cara Login

  1. Buka Browser

    Buka browser (Chrome, Firefox, atau Edge) dan akses https://tritory.id

  2. Masukkan Kredensial

    Isi Email dan Password yang sudah diberikan oleh Admin sistem.

  3. Klik Tombol Login

    Klik "Masuk". Sistem akan mengarahkan ke Dashboard sesuai role kamu.

⚠️
Lupa password? Hubungi Admin sistem untuk reset password. Tidak ada fitur reset mandiri saat ini.

🗺️ Memahami Navigasi

Setelah login, tampilan terdiri dari beberapa area utama:

AreaLokasiFungsi
Sidebar KiriSisi kiri layarMenu navigasi utama ke semua fitur
TopbarAtas layarNotifikasi, profil, dan nama halaman aktif
Area KontenTengah/kananTampilan data dan form input

Menu Sidebar:

  • Dashboard — Eksekutif, Operasional, WIP Monitor
  • Production Order — Daftar dan buat order produksi
  • Cutting Plan — Jadwal cutting (kalender & list)
  • WIP Tracker — Input dan lihat posisi WIP
  • Handover — Serah terima antar stasiun
  • Bahan Baku — Manajemen stok material
  • Budget — Perencanaan dan realisasi biaya
  • Laporan — Berbagai laporan produksi
  • Master Data — Data referensi (Admin only)
  • Users — Manajemen pengguna (Admin only)

👤 Profil & Ganti Password

  1. Klik nama/foto profil di pojok kanan atas topbar

  2. Pilih "Profil Saya"

  3. Update nama, email, atau password, lalu klik Simpan

Dashboard

Pantau kondisi produksi secara real-time

📊 Dashboard Eksekutif

Halaman ini memberikan ringkasan tingkat tinggi untuk manajemen. Tersedia di menu Dashboard → Eksekutif.

Informasi yang tersedia:

Kartu/WidgetKeterangan
Total Order AktifJumlah production order yang sedang berjalan
Total Unit WIPTotal unit yang sedang dalam proses di semua stasiun
Throughput Hari IniJumlah unit yang selesai diproses hari ini
Order TerlambatOrder yang melewati target tanggal selesai
Handover PendingSerah terima yang menunggu konfirmasi
Stok Bahan Baku MenipisMaterial di bawah batas minimum
Grafik WIP per StasiunBar chart WIP di setiap stasiun produksi
Grafik Throughput MingguanLine chart output produksi 7 hari terakhir
Status BudgetPerbandingan rencana vs realisasi anggaran

🔧 Dashboard Operasional

Fokus pada kondisi lantai produksi secara detail. Tersedia di menu Dashboard → Operasional.

  • Status WIP per stasiun (In, Out, Reject, In-Process)
  • Highlight stasiun bottleneck (merah jika melebihi threshold)
  • Daftar handover pending dan discrepancy
  • Aktivitas WIP terbaru (20 entry terakhir)
  • Order yang terlambat dan mendekati deadline

📍 WIP Monitor

Visualisasi posisi produk WIP di setiap stasiun. Tersedia di menu Dashboard → WIP Monitor.

  • Pipeline Flow — Tampilan aliran WIP dari Cutting ke Warehouse
  • Stacked Bar Chart — WIP per order di setiap stasiun
  • Donut Chart — Proporsi WIP per stasiun
  • Tabel Matrix — Baris = Order, Kolom = Stasiun, Isi = Qty WIP
  • Filter Order — Highlight order tertentu di semua visualisasi

Master Data

Data referensi yang digunakan seluruh sistem (Admin only)

ℹ️
Hanya Admin yang bisa mengakses dan mengubah Master Data. Setup master data harus dilakukan sebelum fitur lain bisa digunakan.

📁 Daftar Master Data

Master DataMenuKeterangan
ProdukMaster → ProdukJenis produk yang diproduksi (kaos, jaket, dll)
SeriesMaster → SeriesVarian/koleksi dari setiap produk
WarnaMaster → WarnaPilihan warna untuk SKU
UkuranMaster → UkuranPilihan ukuran (S, M, L, XL, dst)
StasiunMaster → StasiunStasiun produksi beserta urutan dan threshold bottleneck
Tempat SewingMaster → Tempat SewingLokasi/mitra sewing eksternal

⚙️ Cara Tambah Master Data

Prosedur yang sama berlaku untuk semua master data:

  1. Klik menu Master Data → pilih jenis data yang ingin ditambah

  2. Klik tombol "+ Tambah" di pojok kanan atas tabel

  3. Isi form yang tersedia, lalu klik Simpan

  4. Data baru akan muncul di tabel

⚠️
Urutan setup yang disarankan: Produk → Series → Warna → Ukuran → Stasiun → Tempat Sewing. Series harus dibuat setelah Produk karena terhubung.

Data Stasiun memiliki field khusus yang penting:

FieldKeterangan

Urutan (Order Sequence)Angka urutan alur produksi (1=Cutting, 2=Sewing, dst)
Bottleneck ThresholdBatas WIP maksimal sebelum dianggap bottleneck (ditandai merah di dashboard)

Production Order

Buat dan kelola order produksi

📋 Daftar Order

Menu Production Order menampilkan semua order dalam format tabel dengan filter dan pencarian. Setiap baris menampilkan: Nomor Order, Produk, Series, Target Qty, Target Tanggal, dan Status.

Status Order:

Draft — Order belum diaktifkan    Active — Produksi sedang berjalan    Completed — Produksi selesai    Cancelled — Order dibatalkan

➕ Membuat Production Order Baru

  1. Klik "+ Buat Order" di halaman daftar order

  2. Isi informasi utama order:

    • Produk — pilih dari dropdown
    • Series — otomatis muncul setelah pilih produk
    • Nomor PO Buyer — nomor order dari buyer (opsional)
    • Target Tanggal Selesai — deadline produksi
    • Catatan — informasi tambahan

  3. Tambah SKU (item produk)

    Klik "+ Tambah SKU" untuk menambah kombinasi Warna + Ukuran + Qty. Bisa tambah beberapa SKU dalam satu order.

  4. Klik Simpan — order tersimpan dengan status Draft

  5. Untuk mulai produksi, ubah status ke Active via tombol "Ubah Status"

💡
Nomor order (misal: ORD-2026-001) dibuat otomatis oleh sistem.

Cutting Plan

Jadwalkan dan monitor proses cutting

📅 Tampilan Kalender & List

Menu Cutting Plan menyediakan dua tampilan yang bisa di-toggle:

  • Tampilan List — Tabel semua cutting plan dengan filter status
  • Tampilan Kalender — Grid kalender bulanan, cutting plan ditampilkan sebagai badge berwarna sesuai status

Status Cutting Plan:

Draft Scheduled In Progress Completed Cancelled

➕ Membuat Cutting Plan

  1. Klik "+ Buat Cutting Plan"

  2. Isi detail cutting plan:

    • Production Order — pilih order yang akan di-cutting
    • Tanggal Cutting — jadwal pelaksanaan
    • Panjang Marker — dalam meter
    • Lebar Kain — dalam cm
    • Jumlah Layer — jumlah lapisan kain
    • Target Qty — jumlah unit yang akan dipotong
    • Shift — pagi/siang/malam

    Estimasi kain yang dibutuhkan akan dihitung otomatis: Panjang Marker × Jumlah Layer.

  3. Tambah Bundle (opsional)

    Tambahkan rincian bundle per SKU: pilih SKU dari order dan masukkan qty per bundle.

  4. Klik Simpan. Nomor plan (misal: CP-2026-001) dibuat otomatis.

📦 Tracking Bundle

Setiap cutting plan bisa memiliki beberapa bundle. Bundle mewakili kelompok potongan kain per SKU yang siap dikirim ke Sewing.

Status Bundle:

Cut — Sudah dipotong Bundled — Sudah dibundel Sent to Sewing — Sudah dikirim ke Sewing

Update status bundle langsung dari halaman detail Cutting Plan via dropdown di kolom status.

WIP Tracker

Input dan pantau Work In Progress di setiap stasiun

📊 Memahami WIP

WIP (Work In Progress) adalah unit produk yang sedang dalam proses di suatu stasiun. Rumus perhitungan WIP di sistem:

WIP Net = Qty Masuk (In) − Qty Keluar (Out) − Qty Reject

WIP yang tinggi di satu stasiun mengindikasikan potensi bottleneck.

➕ Input WIP

  1. Klik menu WIP Tracker → "+ Input WIP"

  2. Pilih Production Order

    Pilih order yang sedang diproses di stasiun kamu.

  3. Pilih SKU dan Stasiun

    Pilih kombinasi warna+ukuran dan stasiun tempat kamu bekerja.

  4. Isi Qty

    • Qty In — unit yang masuk ke stasiun
    • Qty Out — unit yang selesai diproses dan keluar
    • Qty Reject — unit yang ditolak/cacat

  5. Pilih Tanggal input dan Klik Simpan

💡
WIP bisa di-input harian. Tidak perlu input semua qty sekaligus — bisa bertahap setiap hari sesuai progres aktual.

👁️ Lihat WIP per Order

Klik nomor order di daftar WIP untuk melihat detail progres per stasiun dalam bentuk tabel dan visualisasi bar progress.

Handover (Serah Terima)

Catat perpindahan barang antar stasiun secara digital

🔄 Alur Handover

Buat Handover
→
Status: Pending
→
Penerima Konfirmasi
→
Manager Approve
→
Selesai ✅

Jika qty yang diterima berbeda dengan yang dikirim, status berubah menjadi Discrepancy dan perlu ditindaklanjuti.

➕ Membuat Handover Baru

  1. Klik menu Handover → "+ Buat Handover"

  2. Isi informasi handover:

    • Production Order — order yang barangnya akan diserahkan
    • Dari Stasiun — stasiun pengirim
    • Ke Stasiun — stasiun penerima
    • Tanggal Handover

  3. Pilih Tempat Sewing (jika ke Sewing)

    Jika handover menuju stasiun Sewing, field Tempat Sewing akan muncul otomatis — wajib diisi untuk mencatat ke mitra sewing mana barang dikirim.

  4. Tambah Item Handover

    Klik "+ Tambah Item" untuk setiap SKU. Isi: SKU, Qty Kirim.

  5. Klik Simpan. Status otomatis menjadi Pending.

✅ Konfirmasi Penerimaan

PIC stasiun penerima perlu mengkonfirmasi bahwa barang sudah diterima:

  1. Buka detail handover (klik nomor handover dari daftar)

  2. Isi Qty Diterima untuk setiap item

  3. Klik tombol "Konfirmasi Terima"

  4. Sistem menentukan status otomatis:

    • Qty sama → status Confirmed
    • Qty berbeda → status Discrepancy

✔️ Approve Handover (Manager/Admin)

Setelah dikonfirmasi, Manager perlu menyetujui handover:

  1. Buka detail handover yang statusnya Confirmed atau Discrepancy

  2. Klik tombol "Approve"

  3. Status berubah menjadi Approved — proses selesai

Bahan Baku

Kelola stok dan penerimaan material produksi

📦 Daftar Bahan Baku

Menu Bahan Baku menampilkan semua material yang terdaftar beserta stok saat ini. Material dengan stok di bawah Minimum Stock akan ditandai merah dan memicu notifikasi.

Informasi yang ditampilkan:

  • Kode & Nama Material
  • Satuan (meter, kg, pcs, dll)
  • Stok Saat Ini vs Minimum Stok
  • Status stok (Cukup / Menipis)

➕ Tambah Material Baru

  1. Klik "+ Tambah Bahan Baku"

  2. Isi form:

    • Kode — kode unik material
    • Nama — nama material
    • Satuan — meter, kg, pcs, dll
    • Stok Awal — stok saat pertama kali diinput
    • Minimum Stok — batas bawah untuk trigger alert

  3. Klik Simpan

📥 Catat Penerimaan Bahan Baku

  1. Dari daftar Bahan Baku, klik tombol "Terima" pada material yang datang

  2. Isi form penerimaan:

    • Qty Diterima
    • Tanggal Penerimaan
    • No. Surat Jalan (opsional)
    • Supplier (opsional)
    • Catatan

  3. Klik Simpan — stok otomatis bertambah

Budget & Biaya Produksi

Rencanakan dan pantau anggaran produksi

💰 Daftar Budget

Menu Budget menampilkan semua production order beserta rencana anggaran dan realisasi biaya aktual. Di bagian atas terdapat ringkasan total plan vs total aktual seluruh order.

📝 Input Rencana Anggaran

  1. Klik order di daftar budget → klik "Edit Budget"

  2. Isi rencana biaya per kategori:

    • Biaya Bahan Baku (plan)
    • Biaya Tenaga Kerja (plan)
    • Biaya Overhead (plan)
    • Biaya Lain-lain (plan)

  3. Klik Simpan

💸 Input Biaya Aktual

Biaya aktual diinput per transaksi dari halaman detail budget order:

  1. Buka detail budget order

  2. Klik "+ Tambah Biaya"

  3. Isi form:

    • Kategori Biaya
    • Deskripsi
    • Jumlah (Rp)
    • Tanggal

  4. Klik Simpan — total aktual terupdate otomatis

Manajemen User

Kelola akun pengguna sistem (Admin only)

👥 Daftar User

Menu Users menampilkan semua akun pengguna beserta role dan status aktif/nonaktif.

➕ Tambah User Baru

  1. Klik menu Users → "+ Tambah User"

  2. Isi form:

    • Nama Lengkap
    • Email — digunakan untuk login
    • Password — minimal 8 karakter
    • Role — pilih sesuai tugas pengguna

  3. Klik Simpan — user sudah bisa login langsung

⚠️
Keamanan: Informasikan password ke pengguna baru secara langsung/pribadi. Minta pengguna segera ganti password setelah login pertama.

✏️ Edit & Nonaktifkan User

  • Klik ikon edit ✏️ untuk mengubah nama, email, role, atau reset password
  • Untuk menonaktifkan user (tanpa menghapus), uncheck opsi "Aktif" di form edit
  • User nonaktif tidak bisa login namun data historisnya tetap tersimpan
